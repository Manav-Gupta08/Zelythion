# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ Yes    |

## Reporting a Vulnerability

If you discover a security vulnerability in Zelythion itself, please **do not** open a public GitHub issue.

Instead, report it privately:

**Email:** manavgupta0808@gmail.com

Please include:
- A clear description of the vulnerability.
- Steps to reproduce.
- Potential impact.
- Any proposed mitigations.

You will receive an acknowledgement within **72 hours**.

## Disclosure Policy

We follow a coordinated disclosure approach. Once a fix is available, we will:
1. Release a patched version.
2. Credit the reporter in the changelog (unless you prefer anonymity).
3. Publish a security advisory if the impact warrants it.

## Scope

This policy covers:
- The Zelythion scanner engine.
- The CLI.
- The reporting module.

Out of scope:
- Vulnerabilities in third-party dependencies (report to the relevant project).
- Issues requiring physical access or insider access.
- Social engineering attacks.

## Safe Harbour

We will not pursue legal action against researchers who report vulnerabilities in good faith
and follow this policy.
